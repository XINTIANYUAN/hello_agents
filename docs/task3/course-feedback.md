# Task3 课程内容反馈

第三章把概率计算、Transformer 组件、提示、分词和本地推理连在一起。Bigram 的小语料库适合手算与代码对照，开源模型示例则让读者顺着对话模板、token ID、生成和解码看完整过程。保留这些小例子，并给出明确的可运行入口，能帮助学员逐步核对每一层。 [第三章 大语言模型基础](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md)

- **对齐正文与习题中的本地模型。** 3.2.3 使用 `Qwen/Qwen1.5-0.5B-Chat`，习题 4 推荐 `Qwen/Qwen3-0.6B`。建议分别注明所需依赖版本、模型 ID、对话模板和生成配置，提供一条与习题一致的完整命令。Qwen3 的模型卡还说明了思考模式开关及相应的采样设置，适合直接链接给学员。 [第三章 3.2.3 调用开源大语言模型](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md#323-调用开源大语言模型) · [Qwen3-0.6B 官方模型卡](https://huggingface.co/Qwen/Qwen3-0.6B)
- **给采样练习提供可复查的实验表。** 在同一模型、提示和输出上限下，记录 `do_sample`、温度、`top_p`、`top_k`、随机种子及实际生成 token 数。改变一项配置后重复生成，再比较内容和任务正确率。这样可以帮助读者发现参数是否启用，也能把 3.2.1 的概率分布说明与本地 `generate` 调用对应起来。 [第三章 3.2.1 提示工程](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md#321-提示工程) · [Transformers 生成配置文档](https://huggingface.co/docs/transformers/main_classes/text_generation)
- **在模板后编码的步骤注明特殊 token 的处理。** 正文先调用 `apply_chat_template(tokenize=False)`，再调用分词器。建议在后一步显式设置 `add_special_tokens=False`，或直接让模板函数完成编码，并展示输入长度。Transformers 文档提醒，对话模板已经包含所需特殊 token，额外添加可能导致重复，影响输出。 [第三章 3.2.3 调用开源大语言模型](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md#323-调用开源大语言模型) · [Transformers 对话模板文档](https://huggingface.co/docs/transformers/chat_templating)
- **为 Transformer 骨架补一个组装和形状检查。** 开头的层构造器使用无参占位模块，后续具体实现要求 `d_model`、`num_heads` 等参数。建议在末尾补齐调用位置，给一组小张量与掩码，检查输出形状和因果掩码效果。代码输出也可以放入独立的 `text` 代码块，方便直接复制 Python 部分执行。 [第三章 3.1.2 Transformer 架构解析](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md#312-transformer-架构解析)
- **明确分词算法与工具包的关系。** SentencePiece 支持 BPE 和 Unigram，建议把它的工具角色写清楚，并使用其空格标记 `▁` 的准确字符。再选中英文和 JSON 各一例，展示本次选定模型的真实切分结果及 token 数，读者就能把分词原理用于估计上下文预算。 [第三章 3.2.2 文本分词](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80.md#322-文本分词) · [SentencePiece 官方说明](https://github.com/google/sentencepiece)
