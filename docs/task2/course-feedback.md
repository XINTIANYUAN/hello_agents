# Task2 课程内容反馈

第二章的 ELIZA 练习把历史概念变成了可以读、改和比较的程序。积木世界也在 SHRDLU 和心智社会两节中反复出现，让读者能用同一类任务观察世界状态、动作规则和协作的不同作用。这些例子适合继续用在章末习题。 [第二章 智能体发展史](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2.md)

- **把 ELIZA 源代码和控制台会话放进独立代码块。** 2.2.3 把 `>>>` 和示例会话接在 Python 代码块末尾，整块复制到 `.py` 文件会触发语法错误。建议另用 `text` 代码块展示会话，并给出一组可检查的输入，覆盖规则命中、近义改写与兜底、退出。由于程序随机选择回复模板，验收可以关注触发了哪条规则，以及回复是否来自对应模板。 [第二章 2.2.3 核心逻辑的实现](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2.md#223-核心逻辑的实现)
- **把协作方式放进同一张图里比较。** 2.3.3 可以把去中心化讲成心智社会对多智能体系统的一项启发，再用图示补充由协调者分派任务的设计。以积木塔为例，画出 `GRASP` 失败后哪些模块能知道、谁决定重试、如何结束。课程习题已链接 CAMEL Workforce，其文档中的协调者和执行者可以作为对照。 [第二章 2.3.3 对多智能体系统的理论启发](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2.md#233-对多智能体系统的理论启发) · [CAMEL Workforce 官方文档](https://docs.camel-ai.org/key_modules/workforce)
- **明确 AlphaGo 和 AlphaGo Zero 各自如何训练。** 2.4.2 在介绍早期 AlphaGo 时用了「不依赖人类棋谱」的描述。原团队说明，早期版本先用人类棋局训练，再通过自我对弈改进。AlphaGo Zero 则省去人类棋谱，从自我对弈起步。建议给出两个版本的名称和时间，再用这个对照解释监督学习与强化学习如何结合。 [第二章 2.4.2 基于强化学习的智能体](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2.md#242-基于强化学习的智能体) · [DeepMind 的 AlphaGo Zero 说明](https://deepmind.google/blog/alphago-zero-starting-from-scratch/)
- **在 LLM 智能体架构图旁标明每类状态的作用。** 可以用第一章旅行助手举例，说明预训练发生在模型构建阶段，天气查询更新本次任务的上下文，跨会话记忆需要应用显式保存和读取。这个例子也能帮助读者看懂图 2.10 的「记忆更新」，并理解为什么一次工具调用可以改变下一步行动。 [第二章 2.4.4 基于大语言模型的智能体](https://github.com/datawhalechina/hello-agents/blob/2eb1c7547018b519b85cb57acf5533f12d65bf8e/docs/chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2.md#244-基于大语言模型的智能体) · [第一章旅行助手代码](../../code/chapter1/FirstAgentTest.py)
